# NecroPipeline Demo Repository 🎃

This repository contains intentional bugs for testing the NecroPipeline auto-fix system.

## Intentional Issues

1. **Lint Errors** - Missing semicolons, unused variables, wrong quotes
2. **Test Failures** - Incorrect assertions, wrong expected values
3. **Syntax Errors** - Missing brackets, typos
4. **Import Issues** - Missing module imports

## Running Tests

```bash
npm install
npm test
npm run lint
```

All tests and lints are EXPECTED to fail - this is for demonstration purposes!
